const float motor_config_canopen_torque_reference_current_peak_a
extern

CiA 402 target torque 1000 permille에 대응하는 q-axis current [A peak].

실제 FOC current command limit과 독립적으로 설정할 수 있다. 이 값보다 큰 CANopen target은 FOC limit에서 제한되고 statusword의 internal-limit bit에 반영된다.
