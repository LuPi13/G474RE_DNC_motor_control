Detailed Description

Hall estimator의 연속 전기각 state와 관측 순서를 저장하는 instance.

최초 사용 전 hall_estimator_init()을 호출하고, 이후 내부 field를 application에서 직접 변경하지 않는다. Runtime source of truth는 output이며 update 성공 시에만 갱신된다.
