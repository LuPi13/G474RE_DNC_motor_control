Detailed Description

하드웨어와 무관한 scalar 1차 저역통과 IIR filter.

연속 시간 1차 저역통과 filter의 pole을 matched-pole 방식으로 이산화한다.

cutoff_frequency_hz는 연속 시간 pole에 대응하는 주파수이며 Nyquist frequency보다 작아야 한다. 실행 중에는 미리 계산한 coefficient로 곱셈과 덧셈만 수행한다.

하나의 instance는 하나의 scalar 신호만 소유한다. FOC에서 i_d, i_q를 filtering할 때에는 두 instance를 사용하며, Clarke/Park 변환 뒤의 feedback 경로에 배치한다. 상전류 과전류 보호 경로에는 지연이 생기는 이 filter 출력을 사용하지 않는다.

호출자는 filter_low_pass_update()를 sampling_period_s와 같은 고정 주기로 실행해야 한다. Module 내부에는 scheduler나 prescaler가 없다.

filter_status_t filter_low_pass_init ( filter_low_pass_t * self,
const filter_low_pass_config_t * config,
float initial_output )

1차 저역통과 filter를 설정하고 출력을 지정한 값으로 초기화한다.

Parameters
[out]self초기화할 filter instance.
[in]configCutoff frequency와 고정 sampling period 설정.
[in]initial_output초기 filtered output. 유한한 값이어야 한다.
Precondition
cutoff_frequency_hz < 1 / (2 * sampling_period_s)이어야 한다.
Postcondition
성공하면 coefficient를 한 번 계산하고, 이후 update hot path에서는 expf()를 호출하지 않는다.
Note
Closed-loop enable 시 불필요한 과도 응답을 피하려면 첫 유효 feedback을 initial_output 으로 사용한다.
오류를 반환하면 self 는 변경되지 않는다.
Return values
FILTER_STATUS_OK초기화 완료.
FILTER_STATUS_INVALID_ARGUMENTNULL 인자 또는 유한하지 않은 initial_output.
FILTER_STATUS_INVALID_CONFIG유효하지 않은 cutoff/sampling period 또는 float로 표현할 수 없는 coefficient.
