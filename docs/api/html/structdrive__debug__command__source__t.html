Detailed Description

debugger가 읽고 쓰는 drive command source 상태.

requested_mode, requested_i_d_a, requested_i_q_a, requested_speed_rpm, start_requested, stop_requested만 debugger에서 쓴다. 나머지는 관찰용 결과이며 App 또는 motor control의 canonical state를 복제하지 않는다.
