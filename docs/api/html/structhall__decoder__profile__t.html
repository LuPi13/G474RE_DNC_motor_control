Detailed Description

Motor phase/Hall 배선 조합별 raw-state와 electrical edge angle profile.

Note
Profile은 motor 단품이 아니라 phase wiring과 Hall wiring 조합에 귀속된다. 배선 순서 또는 polarity가 바뀌면 profile도 다시 선택하거나 측정해야 한다.
