Detailed Description

ADC raw code를 상별로 보정하여 3상 전류 [A]로 변환한다.

ADC peripheral 접근은 adc_driver가 담당한다. 이 module은 센서 gain, 무전류 offset, 보정 누적 상태의 유일한 owner이며 HAL이나 peripheral register에 접근하지 않는다. 현재 보드의 ACS725LLCTR-10AB-T 세 개를 동일한 interface로 처리한다.
