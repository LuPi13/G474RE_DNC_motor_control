Detailed Description

3-bit Hall raw state와 edge timing의 hardware-independent snapshot.

Platform driver는 GPIO/TIM capture 결과를 이 값으로 publish하고, Control decoder는 motor profile에 따라 sector, angle, speed를 해석한다. raw signal 자체는 motor profile이나 peripheral handle을 포함하지 않으므로 Common의 계층 독립 value type으로 둔다.
