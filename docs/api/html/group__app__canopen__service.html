CANopenNode와 Object Dictionary를 초기화하고 FDCAN을 시작한다.

Parameters
[out]self초기화할 service instance.
[in]config연결할 App/driver와 Node-ID/bit rate.
[in]default_motor_profilereset 후 사용할 motor parameter.
Precondition
CubeMX FDCAN 및 motor-drive App 초기화를 완료하고 PWM output은 꺼져 있어야 한다.
Return values
CANOPEN_SERVICE_STATUS_OK초기화 및 CAN 시작 완료.
CANOPEN_SERVICE_STATUS_INVALID_ARGUMENTNULL 또는 지원하지 않는 설정.
CANOPEN_SERVICE_STATUS_INVALID_STATEApp/driver/profile 준비 상태가 유효하지 않음.
CANOPEN_SERVICE_STATUS_STACK_ERRORCANopenNode 초기화 실패.

CiA 301 및 CiA 402 slow-loop 처리를 한 번 실행한다.

Parameters
[in,out]self초기화된 service instance.
[in]elapsed_us직전 호출 이후 경과시간 [us], 0보다 커야 함.
[in]i_q_feedback_a마지막 유효 q축 전류 feedback [A].
[in]has_valid_i_q_feedbackfeedback 유효 여부.
[in]omega_e_rad_s마지막 유효 rotor 전기 각속도 [rad/s].
[in]has_valid_speed전기 각속도 유효 여부.
Note
약 1 ms 주기로 main context에서 호출하며 fast ISR에서는 호출하지 않는다.
Return values
CANOPEN_SERVICE_STATUS_OK처리 완료.
CANOPEN_SERVICE_STATUS_RESET_REQUESTEDNMT reset 요청을 수신함.
CANOPEN_SERVICE_STATUS_DRIVE_ERRORApp/PWM 상태 전환 실패.
CANOPEN_SERVICE_STATUS_INVALID_ARGUMENT인자 또는 경과시간이 유효하지 않음.
CANOPEN_SERVICE_STATUS_INVALID_STATE초기화되지 않음.
