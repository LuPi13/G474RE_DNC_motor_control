Detailed Description

한 제어 계산에서 사용하는 3상 전류/DC 전압의 원본 ADC code.

Note
모든 필드의 범위는 [0, 4095]이다. 물리량 환산은 sensor module이 수행한다.
전류 세 개는 완료 묶음에서 복사하며, 전압은 adc_driver_read_raw() 호출 시 읽는다. 전압과 전류의 sampling 시점이 같다는 의미는 아니다.
