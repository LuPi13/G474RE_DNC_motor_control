Detailed Description

PI 설정, 사전 계산 gain 및 runtime 상태를 보관하는 instance.

최초 사용 전 pi_controller_init()을 호출한다. Field를 직접 수정하면 config와 precomputed gain이 불일치할 수 있으므로 공개 API로만 상태를 변경한다.
