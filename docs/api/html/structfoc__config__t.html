Detailed Description

d/q PI, current filter, 전압 사용률과 선택적 motor-model 보상 설정.

d/q PI와 current filter의 sampling period는 모두 같아야 한다. PI error 단위는 [A], output 단위는 [V]다. 내부 scalar 출력 범위는 0 V의 양쪽을 포함하고 외부 원형 제한보다 충분히 넓게 설정하여 d/q vector 방향이 먼저 왜곡되지 않게 한다.
