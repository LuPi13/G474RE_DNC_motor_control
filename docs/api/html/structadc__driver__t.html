Detailed Description

ADC driver의 설정 사본과 수집 상태.

소유권
최초 사용 전에 0으로 초기화하고, 초기화 후 내부 필드를 직접 변경하지 않는다. 한 ADC handle/주변장치는 이 instance가 독점하며 다른 수집 코드와 공유하지 않는다. 환산된 물리량은 이 구조체에 저장하지 않고 App의 feedback으로 전달한다.
실행 문맥
Completion ADC ISR 하나가 세 상을 일괄 수집한다. init/start/stop과 수집 API의 동시 실행은 호출자가 방지한다. 이 구조체는 자체적인 lock이나 여러 실행 문맥 간 snapshot 보호를 제공하지 않는다.
