Detailed Description

Motor-control vector의 Clarke/Park 좌표 변환을 제공하는 무상태 Algorithm 모듈.

좌표계 규약
Clarke 변환은 a상 축과 alpha축을 일치시키는 amplitude-invariant 형식을 사용한다. 입력의 zero-sequence는 제거되며 inverse Clarke는 a + b + c = 0을 가정한다. 따라서 zero-sequence를 포함하는 임의의 3상 입력은 Clarke/inverse Clarke round-trip으로 원래 값 전체를 복원할 수 없다.

Park 변환은 다음 부호 규약을 사용한다.

d = alpha * cos(theta) + beta * sin(theta)
q = -alpha * sin(theta) + beta * cos(theta)

즉, 양의 theta_rad 에 대해 정지 alpha-beta vector를 -theta만큼 회전하여 d-q 좌표로 표현한다. inverse Park는 이 변환의 역변환이다.

삼각함수 계산 책임
이 모듈은 hardware나 CORDIC에 의존하지 않는다. 호출자는 동일한 전기각에서 계산한 sin_theta 와 cos_theta 를 전달한다. 한 fast-loop 안에서 한 번 계산한 값을 Park와 inverse Park에 재사용하면 CORDIC 호출과 각도 표현의 중복을 피할 수 있다.
실행 특성
모든 함수는 내부 상태, 동적 할당, HAL/LL 호출 및 입력 검사를 사용하지 않는다. 따라서 fast-loop/ISR에서 사용할 수 있지만 호출자가 유효한 포인터와 유한한 입력을 보장해야 한다. 입력과 출력 vector의 각 성분은 변환 전후에 같은 물리 단위를 갖는다.

void transform_clarke ( const abc_t * input_abc,
alpha_beta_t * output_alpha_beta )

3상 vector를 정지 alpha-beta 좌표로 Clarke 변환한다.

Parameters
[in]input_abc변환할 a/b/c 성분. 세 성분은 같은 물리 단위를 사용해야 한다.
[out]output_alpha_beta변환 결과. 입력과 같은 물리 단위를 사용한다.
Precondition
input_abc 와 output_alpha_beta 는 유효한 저장 위치여야 한다.
Postcondition
alpha = (2*a - b - c)/3, beta = (b - c)/sqrt(3)가 저장된다.
Note
amplitude-invariant 변환이므로 balanced 3상 입력의 peak magnitude를 보존한다.
입력의 zero-sequence 성분은 출력에 포함되지 않는다.

abc_t * output_abc )

정지 alpha-beta vector를 3상 좌표로 inverse Clarke 변환한다.

Parameters
[in]input_alpha_beta변환할 alpha/beta 성분.
[out]output_abc변환 결과. 입력과 같은 물리 단위를 사용한다.
Precondition
input_alpha_beta 와 output_abc 는 유효한 저장 위치여야 한다.
Postcondition
a = alpha, b = -alpha/2 + sqrt(3)*beta/2, c = -alpha/2 - sqrt(3)*beta/2가 저장된다.
Note
복원되는 3상 vector는 a + b + c = 0이며 zero-sequence를 포함하지 않는다.

회전 d-q vector를 정지 alpha-beta 좌표로 inverse Park 변환한다.

Parameters
[in]input_dq변환할 d/q 성분.
[in]sin_theta기준 전기각의 sine 값.
[in]cos_thetasin_theta 와 같은 기준 전기각의 cosine 값.
[out]output_alpha_beta변환 결과. 입력과 같은 물리 단위를 사용한다.
Precondition
모든 포인터와 입력 값이 유효해야 한다.
sin_theta 와 cos_theta 는 같은 각도에서 계산되어야 한다.
Postcondition
alpha = d*cos_theta - q*sin_theta, beta = d*sin_theta + q*cos_theta가 저장된다.
Note
transform_park()와 같은 sin_theta 및 cos_theta 를 사용하면 서로 역변환 관계가 된다.
