Detailed Description

CiA 402 Profile Torque/Profile Velocity 변환과 OD 표시에 쓰는 motor profile.

Note
torque_reference_current_peak_a는 0x6071의 1000 permille에 대응하는 i_q peak [A]이다. 실제 FOC command limit과 같은 값일 필요는 없으며, 서로 다르면 statusword의 internal-limit bit로 제한 여부를 알린다.
