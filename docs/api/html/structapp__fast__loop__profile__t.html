Detailed Description

Current-mode fast loop의 구간별 cycle 계측 결과.

Note
계측을 켜면 cycle counter read와 결과 갱신 비용이 fast loop에 추가된다. 최종 deadline 판정은 계측을 끈 동일 기능 binary에서도 다시 수행한다.
