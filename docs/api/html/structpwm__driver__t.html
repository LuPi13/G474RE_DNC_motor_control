Detailed Description

PWM driver instance.

선택한 timer와 output은 이 instance가 관리한다. 다른 코드에서 직접 조작하거나 같은 instance의 API를 동시에 호출하면 내부 상태와 hardware가 불일치할 수 있다. 초기화 후 설정과 내부 상태 필드는 직접 변경하지 않는다.

Note
timer_mask와 output_mask는 pwm_driver_init()에서 config를 기준으로 계산되며 이후 enable/disable 시 재사용된다.
is_enabled는 마지막으로 성공한 driver 호출이 기록한 상태이며, 실제 pin 출력이나 hardware fault 상태를 읽은 값이 아니다.
