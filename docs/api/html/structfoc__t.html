Detailed Description

FOC의 stateful Algorithm instance와 motor-model 설정을 소유하는 상태.

외부에서 field를 직접 변경하지 않고 foc_init(), foc_reset(), foc_update()를 사용한다. Input/output snapshot은 instance에 중복 저장하지 않는다.
