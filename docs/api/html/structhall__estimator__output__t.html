Detailed Description

한 fast-loop 주기에서 사용할 연속 rotor electrical state.

theta_e_rad는 Hall edge 사이에서 적분된 값이며 omega_e_rad_s는 가장 최근에 유효했던 Hall 속도 관측값이다. 숫자 field는 대응하는 has_valid_*가 true일 때만 제어에 사용한다. is_sector_limited가 true가 되어도 마지막 속도 관측의 validity는 자동으로 변경하지 않는다. 경계 대기 시간을 이용한 stale/fault 판정은 향후 App 또는 상위 estimator 정책이 담당한다.
