Detailed Description

d/q 전류 feedback을 제어하여 alpha-beta 전압 지령을 만드는 current-control subsystem.

처리 순서
i_abc
-> Clarke / Park
-> d/q low-pass filter
-> d/q PI
-> optional decoupling/feedforward
-> circular voltage limitation
-> PI external tracking
-> inverse Park
-> v_alpha_beta_ref

d/q 전류 지령의 axis/magnitude/rate 제한은 상위 motor_control이 먼저 수행한다. 이 module은 SVPWM, PWM hardware, ADC, current sensor, CORDIC 또는 fault threshold를 소유하지 않는다. 호출자는 같은 전기각에서 계산한 sine/cosine과 offset 보정이 끝난 상전류를 전달한다.

전압 제한과 anti-windup
선형 SVPWM에서 모든 각도에 사용할 수 있는 원형 전압 범위를 사용한다.
voltage_limit = voltage_utilization * v_dc / sqrt(3)

PI와 feedforward를 합친 d/q 전압을 위 범위로 제한한다. 제한이 개입하면 최종 전압에서 feedforward를 뺀 실제 PI 기여분을 pi_controller_apply_tracking()에 전달한다.

Filter 초기화
foc_init()에서는 filter coefficient만 준비하고 feedback 상태는 유효하지 않은 것으로 표시한다. 최초 foc_update()에서 Park 변환한 첫 유효 i_d, i_q로 두 filter를 초기화하므로 0 A에서 시작하는 불필요한 과도 응답을 만들지 않는다.
실행 문맥
foc_update()는 config에 설정된 sampling period와 같은 fast-loop 주기로 한 실행 문맥에서 호출한다. Module 내부에는 scheduler, prescaler, 동적 할당 또는 HAL/LL 접근이 없다.

foc_status_t foc_init ( foc_t * self,
const foc_config_t * config )

FOC configuration과 내부 PI/filter instance를 초기화한다.

Parameters
[out]self초기화할 FOC instance.
[in]configPI/filter, voltage utilization 및 motor-model 설정.
Precondition
d/q PI와 filter의 sampling period가 정확히 같아야 한다.
Decoupling을 활성화하면 Ld와 Lq는 0보다 크고 flux linkage는 0 이상이어야 한다.
Postcondition
PI state는 0 V로 초기화되고 current filter는 첫 update에서 유효 feedback으로 초기화된다.
Note
Decoupling이 비활성 상태여도 motor-model 숫자는 유한하고 0 이상이어야 한다.
오류 반환 시 self 는 변경하지 않는다.
Return values
FOC_STATUS_OK초기화 완료.
FOC_STATUS_INVALID_ARGUMENTself 또는 config가 NULL임.
FOC_STATUS_INVALID_CONFIGPI/filter/model/voltage 설정이 유효하지 않음.

foc_status_t foc_update ( foc_t * self,
const foc_input_t * input,
foc_output_t * output )

FOC 전류 제어의 한 fast-loop 주기를 수행한다.

Parameters
[in,out]self초기화된 FOC instance.
[in]input상전류, 제한된 d/q reference, rotor state 및 DC-link 전압.
[out]output성공 시 current/voltage 계산 결과 snapshot.
Precondition
sin_theta^2 + cos_theta^2는 1에 가까워야 한다.
호출자는 FOC 전에 unfiltered i_abc 과전류 검사와 rotor validity 검사를 완료해야 한다.
output 은 self 또는 input 과 겹치지 않는 별도 저장 위치여야 한다.
Postcondition
성공 시에만 두 filter와 두 PI state, feedback 초기화 상태를 함께 갱신한다.
Note
오류 반환 시 self 와 output 은 변경하지 않는다.
Return values
FOC_STATUS_OKUpdate 완료.
FOC_STATUS_INVALID_ARGUMENTNULL, 비유한 입력, 0 이하 v_dc 또는 유효하지 않은 sin/cos.
FOC_STATUS_INVALID_STATEself가 초기화되지 않음.
FOC_STATUS_FILTER_ERROR내부 filter update/reset 실패.
FOC_STATUS_PI_ERROR내부 PI update/tracking 실패.
FOC_STATUS_NUMERIC_ERROR좌표 변환, feedforward 또는 전압 제한 계산 실패.

App fast loop에서 검증 완료된 입력으로 FOC 한 주기를 실행한다.

Parameters
[in,out]self초기화된 FOC instance.
[in]input상위 경계에서 검증된 전류, reference, rotor 및 DC-link 입력.
[out]output정상 완료 시 계산 결과 snapshot.
Precondition
모든 pointer와 instance 초기화 상태가 유효해야 한다.
i_abc 과전류/유한성, 제한된 i_dq_ref, rotor validity, sin/cos와 v_dc를 App 및 motor_control 경계에서 검증해야 한다.
Postcondition
최종 alpha-beta 전압이 비유한이면 오류를 반환하며 App fault 경로가 controller를 reset한다.
Note
오류 시 runtime state 보존이 필요한 일반 호출자는 foc_update()를 사용한다.
Warning
일반 호출자와 시험 코드는 검증을 수행하는 foc_update()를 사용한다.
Return values
FOC_STATUS_OKFast update 완료.
FOC_STATUS_NUMERIC_ERROR최종 전압 결과가 비유한임.
