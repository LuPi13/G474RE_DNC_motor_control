Detailed Description

최초 fault가 발생했을 때 보존하는 진단 snapshot.

Generic subsystem fault는 가장 최근에 fault_manager_update_measurements()로 전달된 측정값을 보존하므로, 실제 fault 발생 시점보다 앞선 sample일 수 있다.
