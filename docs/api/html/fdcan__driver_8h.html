typedef void(* fdcan_driver_receive_callback_t) (void *context, const fdcan_frame_t *frame)

RX FIFO0에서 꺼낸 frame의 ISR consumer.

Parameters
[in]contextconfig에서 지정한 consumer context.
[in]frame수신 frame. callback 반환 뒤에는 이 pointer가 유효하지 않다.
Warning
FDCAN ISR context에서 호출된다. blocking, HAL 지연 호출 또는 motor-control API 호출은 금지한다.
