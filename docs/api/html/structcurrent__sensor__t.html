Detailed Description

전류 센서 설정, offset 보정 상태와 진단값.

Raw ADC count와 offset 누적 상태는 이 Platform instance만 소유한다. App과 Control은 public API를 통해 보정 상태 또는 환산된 abc_t 전류 [A]만 사용한다.
