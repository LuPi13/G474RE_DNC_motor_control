Detailed Description

Fault 설정, 현재 상태 및 누적 진단값.

update/latch/clear는 하나의 App 실행 문맥에서 직렬화해야 한다. 현재 구성에서는 ADC ISR과 그 후처리만 runtime state를 변경하며, 외부 명령은 App의 비동기 clear request API를 거쳐 전달한다.
