Detailed Description

Speed PI와 mechanical-speed feedback filter 설정.

PI error 단위는 [rad/s], output 단위는 [A]다. PI와 filter의 sampling period는 정확히 같아야 하며 PI 출력 범위는 0 A를 포함해야 한다.
