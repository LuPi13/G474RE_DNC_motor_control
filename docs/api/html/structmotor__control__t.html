Detailed Description

Motor control 설정과 current-reference runtime state.

i_dq_ref는 FOC에 전달할 최종 전류 지령의 유일한 owner다. 외부 target은 호출 입력이며 instance에 복제하지 않는다. FOC state는 이 coordinator가 소유한다.
