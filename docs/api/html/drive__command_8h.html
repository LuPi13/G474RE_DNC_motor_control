Detailed Description

외부 drive command를 App lifecycle API로 전달하는 interface를 정의한다.

CAN, UART, debugger test source는 protocol 해석 뒤 이 module의 command만 만든다. 이 module은 통신 peripheral이나 HAL에 의존하지 않으며, PWM lifecycle의 owner인 App API만 호출한다.

DRIVE_COMMAND_REQUEST_FAULT_CLEAR 

다음 유효 fast-loop sample에서 fault latch clear를 요청한다.

DRIVE_COMMAND_RECOVER_FAULT 

fault clear 뒤 FAULTED에서 READY로 복귀를 요청한다.
