Detailed Description

Rate limiter의 설정과 현재 출력 상태를 보관하는 instance.

최초 사용 전 rate_limiter_init()을 호출한다. Runtime field를 직접 변경하지 않고 reset/set_rates/update API를 사용해야 precomputed step과 설정이 일치한다.
