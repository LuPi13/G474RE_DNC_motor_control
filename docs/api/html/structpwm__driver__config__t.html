Detailed Description

3상 PWM driver의 hardware mapping 설정.

논리적 a, b, c상을 각각 어느 HRTIM sub-timer와 compare unit에 연결할지를 정의한다.

Note
설정값은 초기화 시 복사한다. HRTIM handle은 복제하지 않으므로 원본 handle의 수명은 driver 사용 기간을 포함해야 한다.
Timer mapping 중복과 compare unit 번호만 검증한다. Period, polarity, output source 및 update 방식의 적합성은 호출자가 CubeMX 설정으로 보장한다.
